# TecnoFix S.R.L. - Gestion de presupuestos

App simple para un trabajo practico de facultad. Permite cargar y visualizar un presupuesto de reparacion para una empresa de servicio tecnico.

## Como usarla

1. Abrir `index.html` en el navegador.
2. Completar los datos del cliente, equipo, tecnico, falla y estado.
3. Agregar, editar o eliminar conceptos del presupuesto.
4. Ver el subtotal, IVA y total en la vista previa.
5. Usar el boton de impresion para imprimir o guardar el presupuesto como PDF.

## Funciones incluidas

- Datos generales de TecnoFix S.R.L.
- Formulario de presupuesto.
- Detalle de conceptos con cantidad y precio unitario.
- Calculo automatico de subtotal, IVA y total.
- Vista previa del presupuesto.
- Boton para crear un nuevo presupuesto.
- Diseno adaptable para computadora y celular.
